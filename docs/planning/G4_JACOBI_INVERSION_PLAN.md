# G4 — discharge `AX_curve_generates_jacobian` (Jacobi inversion)

Discharge plan for the third Albanese torus axiom (G4), the only one **independent**
of the G2 self-Albanese linchpin. Goal:

```lean
-- Jacobians/Axioms/TorusAlbanese.lean
axiom AX_curve_generates_jacobian {X} [..] (x₀ : X) (h : 0 < genus X) :
    AddSubgroup.closure (Set.range (Jacobian.ofCurve x₀)) = ⊤
```
"the Abel–Jacobi image group-generates the Jacobian `J = ℂ^g/Λ`."

> **Status (2026-06-14).** Scoped + route chosen (Route A). Confirmed: the
> *substantive* bottleneck is a **Mathlib gap** (closed/connected-subgroup
> structure of a complex torus — no Cartan closed-subgroup theorem, no subtorus
> classification in Mathlib v4.30.0). The repo-buildable half (independent-forms
> / tangent-span, L1) is genuine progress; the Lie-theoretic half (L2) is the
> multi-week residual. This file records the reduction `G4 ⟸ L1 + L2`.

---

## Why the obvious prerequisites don't already give it

- **Abel's theorem** (proved, both directions) gives the **kernel**: `abelJacobiDiv`
  is *injective* on `Div⁰/Prin`. That is **not** surjectivity onto `J`.
- **Riemann–Roch** (`riemannRochL3`, standard-3) is now available — it *would*
  power the classical Jacobi-inversion route (B) below, but that route needs the
  symmetric product `Symᵍ X` as a manifold + properness/degree, which Mathlib
  lacks.
- The **period-spanning** results (`span_real_loopPeriodLattice_eq_top`) say the
  *lattice* spans `ℝ²ᵍ` (so `J` is a genuine torus). G4 is the orthogonal claim
  that the *curve image* (single points, not loops) generates the quotient.

So G4 is genuinely separate and needs new analytic/Lie content.

## Route comparison (Lean-tractability)

**Route A — image not in a proper (complex) subtorus.** The mathematically
cleanest, and it reuses our holomorphic structure:
1. `S := range(ofCurve x₀)` is compact, connected, contains `0` (`ofCurve_self`).
2. `H := ` closed subgroup generated by `S`. Since `S` is connected ∋ 0, `H` is a
   **closed connected** subgroup, and (being the closed image-group of a
   *holomorphic* map) a **complex subtorus** with tangent space a **ℂ-subspace**
   `W ⊆ ℂ^g`.   ← *Mathlib gap (L2)*
3. If `W ⊊ ℂ^g` there is a nonzero ℂ-linear functional `λ` annihilating `W`; as an
   invariant 1-form on `J` it pulls back to `ofCurve*(λ) = Σ λᵢ ωᵢ`, a nonzero
   combination of the basis `ω₁..ω_g` of `H⁰(X,Ω¹)` — but `ofCurve` is *built* so
   that `ofCurve*(dzᵢ) = ωᵢ`, and the `ωᵢ` are linearly independent, so
   `Σ λᵢ ωᵢ ≠ 0`, while it must vanish on `S ⊆ H` (tangent ⊆ `W`). Contradiction.
   Hence `W = ℂ^g`, `H = J = ⊤`.   ← *repo-buildable (L1)*

**Route B — Riemann–Roch / Jacobi inversion.** `riemannRochL3` ⇒ every degree-`g`
class is effective ⇒ `Symᵍ X → J` surjective ⇒ image generates. Needs `Symᵍ X`
manifold + surjectivity (degree/openness). **Mathlib gap is bigger** (symmetric
product manifold theory) and less reused by the rest of the repo.

**Verdict: Route A.** Its only gap (L2) is a *single* standard Lie-theory fact;
Route B's gap (Symᵍ analytic theory) is larger and more bespoke.

## The bottleneck: L2 is a Mathlib gap (confirmed)

Searched Mathlib v4.30.0: **no** Cartan closed-subgroup theorem, **no**
`Subtorus`, **no** closed-connected-subgroup structure for `ℝⁿ/Λ` or a complex
torus (only `Algebra/Module/ZLattice/{Basic,Covolume,Summable}` and a
`dense_submonoidClosure_iff_subgroupClosure` helper). So L2 must be built. Two
sub-options:

- **L2-full**: prove the complex-subtorus structure theorem (`closed connected
  subgroup of ℂ^g/Λ = π(W)`, `W` a ℂ-subspace with `W∩Λ` a full lattice in `W`).
  Multi-week; genuinely Mathlib-grade. Would be reusable (G2 wants the dual fact).
- **L2-axiom (interim)**: capture L2 as a *single, standard, well-vetted*
  Lie/torus axiom and prove **G4 from it + L1**. This trades the somewhat
  Jacobian-specific `AX_curve_generates_jacobian` for a cleaner, more-standard,
  more-vettable torus-structure statement, and isolates exactly the Mathlib debt
  — the same "reduce to a named residual" pattern that worked for T-GEN. **This is
  a "major change" (new axiom) — requires owner sign-off + a tracking issue per
  `CLAUDE.md`; do not land unilaterally.**

## Pitfall log (where Jacobi-inversion formalizations stall)

- **The true bottleneck is L2 (subtorus structure), not RR.** Don't be lured by
  Route B thinking "we have RR now" — Symᵍ manifold theory is the harder gap.
- **ℂ-span vs ℝ-span.** The independent-forms argument only gives the **ℂ-span**
  of tangents `= ℂ^g`. It closes the proof **only because** the generated subtorus
  is *complex* (holomorphic image), so its tangent `W` is a **ℂ-subspace** ⊇ that
  ℂ-span. Skipping "complex" and arguing with ℝ-spans is the classic error (a
  curve can ℝ-fail to span yet ℂ-span); L2 must deliver `W` **ℂ-linear**.
- **Connectivity of the generated subgroup** must be established (else `H` could
  be a dense non-closed or disconnected subgroup and the tangent argument breaks).
