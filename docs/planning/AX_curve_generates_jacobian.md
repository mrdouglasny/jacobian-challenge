# `AX_curve_generates_jacobian` — discharge recipe

**Location:** `Jacobians/Axioms/UniversalProperty.lean:44`
**Route:** provable-from-other-axioms &nbsp;&nbsp; **Effort:** 3 &nbsp;&nbsp; **Est:** ~1–2 focused weeks, ~150 LOC (relies heavily on existing Riemann-Roch and Abel theorem axioms)
**Blocked by:** `Divisor`, `AX_RiemannRoch`, `AX_SerreDuality`, `AX_AbelTheorem`

**Statement (verbatim):**
```lean
axiom AX_curve_generates_jacobian {X : Type*} [TopologicalSpace X] [T2Space X]
    [CompactSpace X] [ConnectedSpace X] [Nonempty X] [ChartedSpace ℂ X]
    [IsManifold 𝓘(ℂ, ℂ) ω X] (x₀ : X) (h : 0 < genus X) :
    AddSubgroup.closure (Set.range (Jacobian.ofCurve x₀)) = ⊤
```

**Why it's an axiom right now:** The docstring (`Jacobians/Axioms/UniversalProperty.lean:24-43`) marks this as the uniqueness half of the Jacobian universal property. It is formalized as a direct corollary of Jacobi inversion: every Jacobian point is a difference of two effective degree-`g` divisors, hence already a sum of `g` Abel–Jacobi images. The load-bearing prerequisites are the dimension count for `H⁰(X, O(D))` from `AX_RiemannRoch`, combined with `AX_AbelTheorem` to map into divisor classes; Codex's 2026-06-02 audit confirmed Mathlib has no Jacobi-inversion / Jacobian-of-a-curve API. (Note: the hypothesis `0 < genus X` avoids the triviality where `Jacobian X` is the zero group, though the statement technically holds even for genus 0).

**Proof recipe**

This is the classical **Jacobi inversion theorem**, realized here as a corollary of other project axioms. References: Miranda, *Algebraic Curves and Riemann Surfaces*. The proof routes through the divisor-level Abel–Jacobi map `abelJacobiDiv : Divisor X →+ Jacobian X` (`Jacobians/Axioms/AbelTheorem.lean:62`) and the effective-divisor sub-monoid.

1. **Reduce the goal to "every `[D] ∈ Jacobian X` is hit by some sum of `g` Abel–Jacobi images of points."** Unfold `AddSubgroup.closure_eq_top_iff` / `AddSubgroup.eq_top_iff`. Since `Jacobian.ofCurve x₀ P = abelJacobiDiv X ((P : Divisor X) - (x₀ : Divisor X))` once the `Divisor` stub lands (compose `ofCurveImpl` at `Jacobians/Axioms/AbelJacobiMap.lean:229` through `abelJacobiDiv` at `Jacobians/Axioms/AbelTheorem.lean:62`), it suffices to show every `j : Jacobian X` is `abelJacobiDiv X (∑ᵢ Pᵢ − g · x₀)` for some `P₁, …, P_g ∈ X`.

2. **Lift to a divisor class and apply Riemann–Roch.** For an arbitrary base divisor `D₀` of degree `g` (e.g. `g · x₀`), pick any `j ∈ Jacobian X` and lift it to a divisor class `[E − D₀]` with `deg E = g` using `AX_AbelTheorem` (`Jacobians/Axioms/AbelTheorem.lean:69`). Apply `AX_RiemannRoch` (`Jacobians/Axioms/RiemannRoch.lean:61-66`) to `E`, which is typed via `H¹`:
   `h⁰(O(E)) − h¹(O(E)) = deg E + 1 − g = 1` (using `deg E = g`).
   Bridge to the canonical formulation by applying `AX_SerreDuality` to convert `H¹(O(E))` to `Dual(H⁰(O(K − E)))`, yielding `h¹(O(E)) = h⁰(O(K − E))`. Substituting gives the standard dimension count
   `h⁰(O(E)) − h⁰(O(K − E)) = 1`,
   so `h⁰(O(E)) ≥ 1`. Hence, there exists a non-zero global section $s \in H^0(X, O(E))$.

3. **Section-to-divisor correspondence.** To formally conclude that the divisor class $|E|$ is non-empty, use the `Section -> Divisor` correspondence API (which must be built). Define $E' = \text{divisorOfSection}(s)$. Prove that the vanishing locus of a non-zero section gives an effective divisor ($E' \ge 0$) and that $E' \sim E$ (they are linearly equivalent). Because degree is invariant under linear equivalence, `deg E' = g`.

4. **Repackage `E'` as `∑ᵢ Pᵢ`.** Once `Divisor X = FreeAbelianGroup X` lands (current stubs at `Jacobians/RiemannSurface/LineBundle.lean:51` and `:56`), an effective divisor of degree `g` is exactly `P₁ + ⋯ + P_g` (with multiplicity) for some `Pᵢ : X`. Decompose `E' = ∑ᵢ (Pᵢ : Divisor X)` via the standard `FreeAbelianGroup.toFinsupp` / `Finsupp.sum_single` lemmas.

5. **Assemble the Abel–Jacobi sum.** From Step 3, `[E'] = [E]` in `Pic(X)`, so `abelJacobiDiv X (E' − g · x₀) = j` in `Jacobian X`. Expanding `E' − g · x₀ = ∑ᵢ ((Pᵢ : Divisor X) − (x₀ : Divisor X))` and using `AddMonoidHom.map_sum`, this becomes `∑ᵢ Jacobian.ofCurve x₀ Pᵢ` (requires a small `ofCurve_eq_abelJacobiDiv` glue lemma analogous to the existing `Jacobians/Extensions/AbelJacobi.lean:163-165` two-point identity).

6. **Conclude `closure (range ofCurve x₀) = ⊤`.** Each `j ∈ Jacobian X` is now exhibited as a finite sum `∑ᵢ Jacobian.ofCurve x₀ Pᵢ`, i.e., lies in the additive submonoid generated by `Set.range (Jacobian.ofCurve x₀)`. A fortiori it lies in `AddSubgroup.closure (Set.range (Jacobian.ofCurve x₀))`. Therefore that closure is all of `Jacobian X`. Finish with: replace `axiom AX_curve_generates_jacobian` with `theorem AX_curve_generates_jacobian` in `Jacobians/Axioms/UniversalProperty.lean`.

**Next discrete deliverable.** Step 3 — formalising the `Section -> Divisor` correspondence. Specifically, establishing the machinery to construct `divisorOfSection (s : H⁰(X, O(E)))` and prove `IsEffective (divisorOfSection s)` and `divisorOfSection s ∼ E` when $s \neq 0$. This API bridges the algebraic dimension count with the geometric existence of an effective divisor.
