## 2. The sharpened minimal residual (work item 2)

### 2.1 The correction: T-GEN is a separate, necessary input

The study's 3(a) splitting argument used "`range φ = Λ`". That is **not
free**: `devValPeriodVec` is defined on every `H1` class (developing values
along arbitrary *continuous* loop classes), while `loopPeriodLattice` is the
ℤ-span of *analytic*-loop periods. The gap is

> **T-GEN** (`AnalyticLoopsGenerateH1 x₀`):
> `span ℤ (range loopToHomology) = ⊤` in `H1 X x₀`.

* **Necessary** for the axiom's H₁ fields: any basis tied to analytic loops
  by `loops_to_basis` spans, so loop classes generate
  (`analyticLoopsGenerateH1_of_h1LoopBasis`).
* **Not implied by T-FG.** `Group.FG (FundamentalGroup X x₀)` supplies
  finitely many *continuous* generators; the toy model
  `loopSpan = 2ℤ × ℤ ⊂ ℤ² = H1` satisfies T-FG + T-RANK + KER-0 yet admits
  no analytic-loop basis. The existing #198 chain never met this because
  `PeriodGeneratingLoops` quantifies only over analytic loops; the `isBasis`
  field quantifies over all of `H1`.
* **Feasibility (vs #227).** This is the natural strengthening of T-FG that
  the lasso/slit-sheet lane produces anyway: its π₁ generators
  (`normalClosure_isolatingLassos_eq_top`, `Topology/IsolatingLasso.lean:294`)
  are *concrete piecewise-analytic* loops, and their lifts along the
  branched cover stay piecewise-analytic. An abstract `Group.FG` result
  would NOT suffice for the flip; the lane should state its output as
  "π₁ generated by [specific analytic loops]" — T-GEN then follows through
  abelianization. Under T-GEN, the #198 subgroup trick upgrades to: every
  `H1` class is a **single** analytic-loop class
  (`AnalyticLoopsGenerateH1.exists_loop`) — no smoothing problem remains
  anywhere downstream.

### 2.2 The exact residual, given K-LITE

Conditional on `[DiscreteTopology (loopPeriodLattice x₀ b)]`, the three H₁
fields are **equivalent** to either package:

* **Sharp form:** T-GEN + **KER-0**, where
  KER-0 := `∀ v : H1, devValPeriodVec x₀ b v = 0 → v = 0`
  (period-injectivity on `H1`);
* **Topology-lane form:** T-GEN + T-FG (`Module.Finite ℤ H1`) +
  `Module.Free ℤ H1` + T-RANK(≤) (`finrank ℤ H1 ≤ 2g`).

Sufficiency of both is `exists_h1LoopBasis_of_periodInjective` /
`_of_topology`; necessity: T-GEN and `finrank = 2g` (hence rank ≤, Finite,
Free via `Module.Free.of_basis`) follow from the fields
(`analyticLoopsGenerateH1_of_h1LoopBasis`, `finrank_h1_of_h1LoopBasis`),
and KER-0 follows from the fields + K-LITE by the same rank bookkeeping.

### 2.3 Why KER-0 stops being Hodge-hard here

`TRANK_SCOPING.md` §2 rated period-injectivity-grade content (TR-DISC
kernel) as the "irreducible analytic core" (de Rham + Hodge, multi-week),
and §3 (GC-2) showed the keystone cannot bound `rank H1`. The splitting
moves that wall entirely into K-LITE: once Λ has ℤ-rank exactly `2g`
(K-route, residue-theorem side), KER-0 reduces to **pure topology** —
`finrank H1 = finrank ker + 2g ≤ 2g` forces `ker = 0`
(`h1PeriodInjective_of_finrank_le`). Note the torsion content is honest:
torsion classes always have zero periods, so KER-0 ⊆ "H1 torsion-free";
that is carried by `Module.Free ℤ H1`, which the `isBasis` field needs
anyway — there is no torsion-free-avoidance for the H₁ fields (contrast
the image route, where TR-TORS drops; `TRANK_SCOPING.md` §3 applies to the
*lattice* consumers only).
